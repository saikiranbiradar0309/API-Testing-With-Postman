07. How to Save API Response in Variable

    - When we are creating a booking, it is generating a booking id
    - We are using same id to get more details about that booking
    - As well as if we want to update anything we need to update by the same booking id
    - Also in our case we are using that booking id in DELETE request also


    - Goto Create Booking --> Scripts --> 
      Write the below JavaScript code
      

      // The first line reads the booking ID from the response,

      var jsonData = pm.response.json();

      // and the second line stores it so you can use it in another API request without hardcoding the ID.
      pm.environment.set("b_id", jsonData.bookingid);

      --> Send

      --> Goto the Environment variables --> Inside Booking API -->
          You can see Variable as b_id and value as 1505

    - Now, if you got and check environment variables there is another 
      environment variable created as b_token and tokenvalue


    - In the Update and Delete Booking we are using this env variable in the
      Headers

12. How to verify status code using JavaScript in Postman
    
    - Goto Positive Endpoints --> Create Booking
      --> write below code

        pm.test("Verify Status Code is 200", function() {
            pm.response.to.have.status(200);
        })


        Full code with Variables

            var jsonData = pm.response.json();

            pm.environment.set("b_id", jsonData.bookingid);


            pm.test("Verify Status Code is 200", function (){
                pm.response.to.have.status(200);
            });
    

    - Once you click on send --> Goto Test Results 
      --> You can see it as Passed 
    

    - If you change a status code here in the code For example:

        pm.test("Verify Status Code is 200", function() {
                    pm.response.to.have.status(201);
                })
    

     - Once you click on send --> Goto Test Results 
       --> You can see it as Failed

16. Verify the Content Type is application/json for Response Headers

        var jsonData = pm.response.json();

        pm.environment.set("b_id", jsonData.bookingid);


        pm.test("Verify Status Code is 200", function (){
            pm.response.to.have.status(200);
        });

        pm.test("Verify Body matches string", function () {
            pm.expect(pm.response.text()).to.include("Abhi");
        });


        pm.test("Content-Type is present", function () {
            pm.response.to.have.header("Content-Type", "application/json; charset=utf-8");
        });
