03. How to execute Standard HTML Report after Executing the Postman Collections
    from the Terminal

    a. Install npm newman reporter html package
       npm i -g newman-reporter-html 

    
    b. Generate the HTML Report
       newman run "Booking API.postman_collection.json" -e "Booking API.postman_environment.json" -r html

    c. After executing above command a folder will be created on the name like newman 
       and in that you can have the HTML Report.


====================================================


04. How to Generate Advanced HTML Report

    a. Install npm newman reporter html extra package
       npm i -g newman-reporter-htmlextra

    b. Generate the HTML Report
       newman run "Booking API.postman_collection.json" -e "Booking API.postman_environment.json" -r cli,htmlextra

    c.  c. After executing above command a folder will be created on the name like newman 
       and in that you can have the HTML Report.

06. verify API response JSON Schema 

    - Goto Get Booking Details --> Copy the Response
      --> Search Convert JSON to JSON Schema --> Visit any website
      --> Paste the Response --> Generate
      --> Copy the Generated Schema
      --> Goto Get Booking Details
      --> Scripts
      --> Write below code

            const expectedJSONSchema = 
            {
            "type": "object",
            "properties": {
                "firstname": {
                "type": "string"
                },
                "lastname": {
                "type": "string"
                },
                "totalprice": {
                "type": "integer"
                },
                "depositpaid": {
                "type": "boolean"
                },
                "bookingdates": {
                "type": "object",
                "properties": {
                    "checkin": {
                    "type": "string"
                    },
                    "checkout": {
                    "type": "string"
                    }
                },
                "required": [
                    "checkin",
                    "checkout"
                ]
                },
                "additionalneeds": {
                "type": "string"
                }
            },
            "required": [
                "firstname",
                "lastname",
                "totalprice",
                "depositpaid",

                "additionalneeds"
            ]

      --> No rocket science here, Just pasted the copied schema from schema generator
